# 产品重新导入说明

## ⚠️ 重要警告

此脚本会**删除所有现有产品数据**及以下相关记录：
- 所有产品记录
- 所有库存移动记录（库存流水）
- 所有采购订单项
- 所有销售订单项
- 所有BOM物料清单项
- 所有生产报表项

**执行前请确保：**
1. 已备份数据库（特别是正式环境）
2. 确认可以接受数据丢失
3. 确保CSV文件路径正确且完整

## 使用方法

### 交互式运行（推荐，会要求确认）

```bash
cd backend
python reimport_products.py
```

脚本会显示当前数据库统计信息，并要求输入 `YES` 确认后才执行删除操作。

### 非交互式运行（跳过确认，直接执行）

```bash
cd backend
python reimport_products.py --yes
```

### 指定CSV文件

```bash
python reimport_products.py "產品品項管理 - 工作表1.csv"
# 或
python reimport_products.py --yes "產品品項管理 - 工作表1.csv"
```

## 执行步骤

脚本会按以下步骤执行：

1. **显示当前数据统计**：显示数据库中现有的产品数量和相关记录数量
2. **确认删除**（除非使用 `--yes`）：要求输入 `YES` 确认
3. **删除数据**：按顺序删除所有相关数据
4. **重新导入**：从CSV文件导入所有产品
5. **验证结果**：统计导入的产品数量，并与CSV文件中的数量进行对比

## 验证导入结果

脚本执行完成后会显示：
- 总产品数
- 竹筷产品数量
- 其他产品数量
- CSV文件中的产品数
- 前10个样本产品

如果导入数量与CSV数量一致，说明导入成功。

## 故障排查

如果导入失败或数量不一致：

1. **检查CSV文件格式**：确保文件编码为 UTF-8，列名正确
2. **查看错误信息**：脚本会显示详细的错误信息
3. **检查数据库连接**：确保数据库文件可访问
4. **检查产品名称**：确保CSV中没有空的产品名称（会被跳过）

## 修复内容

此脚本已修复以下问题：
- ✅ CSV列名包含换行符的问题（`件入數\n(箱入數)`）
- ✅ 确保所有字段都能正确读取和导入
- ✅ 竹筷系列产品现在可以正确导入
